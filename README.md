# 灯又红了（red-again）

每天走同一条路，红绿灯总是一个接一个变红？把路上几个灯的周期、绿灯长度和变绿时刻记下来，按你的速度推一遍：要停几次、路口一共耽误多久，开快开慢、早几秒晚几秒出门能不能一路绿。

- 单页静态应用：`index.html` + `core.js`（计算）+ `ui.js`（界面），不联网、不收集数据，条件只存在本机 localStorage。
- 模型：定时信号灯（固定周期、绿灯区间左闭右开）+ 匀速 + 起步损失，只有你一个人。时间按分数精确算。不算排队车辆、加减速、感应灯。
- 测试：`node --test tests/core.test.cjs`；独立 Python 参考实现 `tests/ref.py`（Fraction）生成 `tests/ref.json`（300 组）。
- 默认数字是虚构示例。别为赶绿灯超速。
